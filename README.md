# Dance Tonight · 100 天腹肌燃脂计划（桌面版）

**Read this in other languages:** [English](docs/README.en.md) · [Español](docs/README.es.md) · [Русский](docs/README.ru.md) · [日本語](docs/README.ja.md) · [한국어](docs/README.ko.md) · [Français](docs/README.fr.md) · [Deutsch](docs/README.de.md) · [Português](docs/README.pt.md) · [العربية](docs/README.ar.md)

跟着音乐做动作的健身游戏，也是一套 3D 舞蹈跟练工具。健身动作由摄像头判断到位程度并按准确度、节奏打分；复杂舞蹈以看教练、学分步、跟完编舞为主。屏幕上的 VRM 教练会连续示范，语音提前提示下一个动作。

支持 Windows、macOS 和 Linux。全部在本机运行，不需要服务器，摄像头画面不会离开你的电脑。

## 功能

| 模式 | 说明 |
|---|---|
| **今日训练** | 按 100 天计划自动挑歌，凑够当天的时长。动作的密度和种类随天数逐步提升，每第 7 天是恢复日 |
| **竞速挑战** | 适合 125 BPM 以上的快歌（DJ 等）。每拍一个动作，用血条计分：PERFECT +3、GREAT +1、GOOD −4、MISS −14，血条空了挑战失败；可以开启逐渐加速；每首歌有自己的排行榜 |
| **动作教学** | 一次练一个动作。教练循环示范，屏幕上有实时匹配度条和次数统计 |
| **现代舞跟学** | 真人动作捕捉驱动的 3D 教练：导入 Mixamo FBX / BVH / VRMA 动捕文件跟着学。0.25～1 倍速、分节循环、镜面、拖动 360° 看动作、摄像头并排对照 |
| **舞蹈模式** | 27 个舞蹈动作/左右变体、四套编舞（星光律动/街区摇摆/流光身段/旋转舞台），每套 4 个 8 拍段落。先慢速分段跟练，再选歌完整表演；复杂动作按分步骤教学和完成度进行，不受 2D 转身识别限制 |

- **热量估算**：按"实际命中的动作 × 动作 MET × 每拍时长 × 体重 + 基础消耗"计算——漏掉的动作不计热量，比按整首歌时长乘固定系数合理得多。MET 表在 `web/js/core/moves.js`（`MOVE_MET`）和 `web/js/dance/dancemoves.js`（`DANCE_MET`）。
- **腹肌与体脂**：腹肌能不能看见取决于体脂率，练腹本身不局部减脂。坚持训练 + 记录腰围，腰围/身高比降到 0.5 以下是比体重更可靠的进步信号（首页趋势图现在同时画体重和腰围）。
- **舞蹈动作**：基础动作包括迪斯科、拍手、比心、Vogue、甩手、扭胯、达布和弹跳；进阶动作包括身体 wave/roll、手臂 wave、胸震、肩 roll、并步、交叉步、左右 360° 转身及背身波浪。进阶动作使用多拍连续关键帧，真正经过正面、侧面和背面，并带前后重心位移；练习时显示分步骤提示和演示进度，不要求摄像头识别背影。
- **3D 教练**：使用 VRM 形象，镜像示范（你抬左腿，她抬右腿，就像照镜子），刚好在节拍点做到位。教练窗口可以拖动、缩放，位置会记住。连击时她会笑。
- **语音教练**：10 种界面语言全部内置离线语音包，开箱即用：
  - 中文内置 CosyVoice 发音人「龙华」（longhua_v3.1）；其余 9 种语言（英/西/俄/日/韩/法/德/葡/阿）用微软 Edge 神经语音生成，统一女声、音质与中文相当；全部随仓库一起分发，开箱即用；
  - 语音包在 `assets/tts/`：`longhua_v3.1@zh/` 为中文，`edge@<语言>/` 为其他语言；可在设置里用自己的录音替换当前界面语言的语音；
  - 开局倒数"三、二、一"，每组动作开头会报"左右交替抬膝"之类的提示；
  - 每句话都会在节拍点前念完，念的时候音乐自动压低；
  - 中途会给鼓励，比如"已经一半了""连击不断"；舞蹈模式下每个动作都会报名字（"左手指天""甩手向左"…）。
- 台词集中在 `web/js/core/cue_texts.js`；9 种非中文语音包可用 `python3 scripts/gen_voices_edge.py` 重新生成（自动只补缺失的），中文包可在设置里上传录音替换。
- **多语言界面**：10 种语言（中/英/西/俄/日/韩/法/德/葡/阿，阿拉伯语自动切 RTL）覆盖全部界面，不只是设置页——首页、曲库、动作教学、舞蹈、编舞编辑器、动捕工作室、游戏与结果页，以及动作名称、教学步骤、四套内置编舞、气泡提示、错误信息都在内。
  - 文案在 `web/js/i18n/locales.js`（每种语言 397 条 key，中文为源语言与兜底），词表在 `movetexts.js`（27 个舞蹈动作 + 16 个健身动作的名称/提示/分步教学）、`routinetexts.js`（内置编舞）、`cliptexts.js`（动捕片段）；
  - 静态骨架用 `data-i18n` / `data-i18n-placeholder` / `data-i18n-aria` / `data-i18n-title` 标注，动态文本用 `t("key")`，带参用 `t("key", { n })`；
  - 切语言即时生效，无需重启；主进程与节拍分析 Worker 也会同步语言，所以校验报错和「音频太短」这类提示同样会跟着变；
  - `npm test` 会先跑 `scripts/check_i18n_keys.mjs`：界面引用的每个 key 必须在 10 个语言包里都存在，漏译直接失败。
- **盲练模式**：每个动作都报"左""右"，节拍点有提示音。戴着耳机、闭着眼睛也能跟着练。
- **节拍分析**：内置 Beat This!（ISMIR 2024 的节拍识别模型，int8 量化，22MB），在后台 Worker 里运行，每首歌约 8 秒。在 49 首测试歌曲上：
  - 速度识别对了 48 首（librosa 只对了约一半，慢歌经常被识别成两倍速度）；
  - 节拍位置和原版 PyTorch 模型的吻合度 F = 0.995。
  - 如果模型加载失败，会自动改用内置的纯 JS 节拍算法。

## 动作

**健身动作**（按解锁等级）：

| 等级 | 动作 | 主要锻炼 |
|---|---|---|
| 1 | 🙌 双手上举 · 👊 左/右冲拳 | 有氧、肩 |
| 1 | 🍑 深蹲 | 腿臀（按膝盖角度判深度） |
| 1 | 🦵 左/右提膝 · 🤸 摸脚尖 | 腹肌、后侧链 |
| 2 | ⭐ 开合跳 | 有氧 |
| 2 | ✖️ 左膝碰右肘 / 右膝碰左肘 | 腹斜肌 |
| 2 | 🦵 左/右侧提膝 · 🦶 左/右前踢腿 | 腹斜肌、臀、核心稳定 |
| 3 | 🌙 左/右侧弯（可保持） | 侧腹 |

**舞蹈动作**（27 个动作/左右变体）：迪斯科指天、胸前拍手、双手比心、时尚造型、左右甩手、扭胯、达布、弹跳律动，以及身体波浪、身体绕环、左右手臂波浪、胸口震点、肩膀绕环、左右并步、左右交叉步、左右旋转和背身波浪。

想学更多爵士/现代舞：在 [Mixamo](https://www.mixamo.com/) 搜索 Jazz / Contemporary / Dance，下载格式选 **FBX Binary**、Skin 选 **Without Skin**，然后在「舞蹈 → 导入动捕文件」导入（可以一次多选几十个文件，逐个转换，损坏的文件会单独列出、不影响其他文件）。导入时会自动识别骨骼（Mixamo、CMU、常见 BVH、VRMA）、校正坐标轴和朝向、对齐 A/T 姿势差异、去掉捕捉抖动并裁掉首尾静止段；转换后的数据保存在本机数据目录的 `dances/`。

**自己编舞**：在「舞蹈 → 我的编舞 → 新建编舞」里，把右侧动作库里的动作拖进序列（拖到两个动作之间就插在那里），或直接点动作加在选中动作后面；序列里的动作可以拖动调整顺序、按 Delete 删除、一键左右镜像。每个动作按自己的长度占时间：普通动作 1 拍，转身/波浪等按各自拍数，动捕（导入的和内置现代舞都有）整段原速播放，下一个动作从紧接着的拍子开始。表演时选一首歌，从第一个动作跳到最后一个动作结束（音乐随之淡出）；分段练习会自动把序列按约 8 拍分成几段。内置编舞可以「复制改编」作为起点。编舞保存在数据目录的 `data/data.json` 里。

**进阶编舞**：「流光身段」侧重身体线条、手臂 wave 和胸肩 isolation；「旋转舞台」侧重侧向脚步、完整转身和背身组合。多拍动作按 2 或 4 拍完整演示，不会在动画中途切换。

## 从源码运行（三个平台通用）

需要 Node.js 20 或更高版本。

```bash
npm install      # 依赖走 npmmirror（见 .npmrc），装完自动把 MediaPipe/three.js/onnxruntime 拷进 web/vendor
npm start
```

第一次 `npm install` 会从 Google Storage 下载一个约 5.8MB 的姿态模型。如果下载失败，配置好代理后重新运行 `node scripts/vendor.mjs` 即可。

`assets/` 目录里放着内置资源，打包时会一起带上。仓库只内置**最小验证包**（大体积/个人资源不入库）：

| 路径 | 内容 |
|---|---|
| `assets/models/beat_this_final0.int8.onnx` | 节拍模型（Beat This! int8，MIT，见 NOTICE） |
| `assets/avatars/RealMaster.vrm` `SportGirl.vrm` | 内置教练形象（各模型许可见 NOTICE） |
| `assets/dances/*.json` | 3 段内置动捕舞蹈 |
| `assets/tts/longhua_v3.1@zh/` `edge@<语言>/` | 离线语音包：10 种语言全部随仓库分发，可在设置里上传自己的录音替换 |
| `samples/demo-song.mp3` | 示例歌曲，用于最小验证 |

**最小验证流程**：`npm install && npm start` → 曲库 → 添加文件 → 选 `samples/demo-song.mp3` → 等节拍分析完成 → 首页开始训练；或去「舞蹈」页直接跟练内置动捕。

**更多资源**：
- VRM 教练形象：在 [VRoid Hub](https://hub.vroid.com/) 下载喜欢的形象（注意每个模型的授权条款），然后在「设置 → 教练形象」导入；
- 动捕文件：应用内「舞蹈」页有 [Mixamo](https://www.mixamo.com/) 入口，下载选 **FBX Binary + Without Skin**，批量导入即可；
- 歌曲：自己导入，相同内容只存一份副本。

## 跨设备数据迁移

应用不联网、不注册，所有数据保存在本机。要把数据搬到另一台设备，用「设置 → 导出 / 导入数据包」生成 `.dtx` 文件：分项勾选（锻炼 / 体重 / 编舞 / 动捕 / 歌曲 / 节拍分析 / 设置）、gzip 压缩、SM9 国密加密——加密口令由「账号标识 + 口令」派生，不经过任何服务器，另一台设备用相同的账号 + 口令即可解密导入。

## 第一次使用

1. **曲库 → 添加整个文件夹**：选择你的音乐目录，后台会开始分析节拍。音乐会复制一份到软件的数据目录（相同内容只存一份），之后原文件可以删除或移动。以前导入的歌曲会在启动时自动补复制。
2. 如果这些歌之前放在 GPU 服务器上，可以去 **设置 → 导入节拍分析包**，导入 `beat_pack.json`，匹配上的歌就不用再分析了。
3. **设置 → 导入旧版数据**：导入 `legacy.json`，包括服务器版的训练记录、体重和计划开始日期。
4. 想用自己的声音？在 **设置 → 语音教练** 里上传录音即可替换当前语言的语音（文件名与台词文本一致），也可一键恢复内置语音包。
5. 先去 **动作教学** 把每个动作练一遍，再回首页开始训练。

摆位建议：人离摄像头 2.5~3 米，全身入镜（包括脚踝），光线从正面照。每首歌开始前站直、双手自然下垂约 1 秒完成校准。

| 按键 | 作用 |
|---|---|
| 空格 | 跳过校准 / 暂停 |
| Esc | 结束这首歌 |

## 数据保存在哪里

| 系统 | 位置 |
|---|---|
| Windows | `%APPDATA%\Dance Tonight\` |
| macOS | `~/Library/Application Support/Dance Tonight/` |
| Linux | `~/.config/Dance Tonight/` |

目录里的 `data/data.json` 保存进度、成绩和体重，`data/analysis/` 保存每首歌的节拍分析，`music/` 保存导入歌曲的副本，`tts/`、`avatars/` 和 `dances/` 保存你自己生成的语音、导入的形象和导入的动捕舞蹈。导入后原文件都可以删除；备份或换电脑时复制整个目录即可。在曲库删除歌曲时，会一并删除它在 `music/` 里的副本（不会动你的原文件）。

## 开发

```bash
npm test                          # 单元测试与覆盖率
python3 scripts/gen_voices_edge.py  # 可选：重新生成其他 9 种语言的语音包（pip install edge-tts）
npm run test:coach                # 14 个基础舞蹈动作 × 3 个 VRM，真实关节送入判定器
npm run test:motion               # 13 个进阶动作 × 5 阶段 × 3 个 VRM，验证并截图
npm run test:mocap                # 动捕舞蹈 × 3 个 VRM 渲染检查 + 跟学界面/导入流程
npm run e2e                       # Electron 全流程 + 上述两类教练回归
DT_E2E_EXE=dist/linux-unpacked/dance-tonight npm run e2e   # 测试打包后的程序
node e2e/pose_gallery.mjs         # 全部健身/舞蹈姿势对照图（连续动作取中段）
node e2e/coach_motion.mjs /tmp/dt-motion  # 五阶段动作接触表
node scripts/eval_beats.mjs <歌曲目录> <参考结果.json> beatthis   # 节拍精度评估
```

目录结构：

| 目录 | 内容 |
|---|---|
| `electron/` | 主进程：窗口、`app://` 协议（跨域隔离，WASM 多线程需要）、进程间调用、本地 JSON 存储、语音包管理、VRM 管理 |
| `web/js/core/` | 动作目录、100 天计划、谱面生成、语音台词。主进程和界面共用 |
| `web/js/analysis/` | 纯 JS 节拍算法、Beat This! 的预处理和后处理、分析 Worker |
| `web/js/coach/` | 3D 教练：three.js + three-vrm，以及姿势和时间曲线 |
| `web/js/voice/` | 语音提示的时间规划（纯函数）和 Web Audio 播放 |

## 已知限制

- 动作判定的阈值只在合成姿势上测过，**还没有用真人校准**。如果某个动作做到位了却总是判不满，告诉我，或者调整 `web/js/judge.js` 里的 `MATCHERS`。
- 识别只用了 2D 正面视角，看不准身体前后方向和背身动作。因此**健身动作仍选择容易正面检测的姿势；转身、背身和 depth 动作只用于舞蹈引导学习**，不依赖关节匹配评分。
- 基础舞蹈动作的判定阈值只在合成姿势上校准过，真人跳的时候如果觉得判分偏松或偏紧，调 `web/js/dance/dancemoves.js` 里的 `DANCE_MATCHERS`。进阶引导动作以跟练完成为准，不把该数值当作真人舞姿准确性。
- Windows 和 macOS 版目前只在 Linux 上打过包，**还没有在真机上运行测试过**。
