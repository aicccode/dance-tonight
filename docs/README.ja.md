# Dance Tonight · 100日間腹筋燃焼プラン（デスクトップ版）

[![CI](https://github.com/aicccode/dance-tonight/actions/workflows/ci.yml/badge.svg)](https://github.com/aicccode/dance-tonight/actions/workflows/ci.yml) [![Release](https://img.shields.io/github/v/release/aicccode/dance-tonight?sort=semver)](https://github.com/aicccode/dance-tonight/releases/latest) [![License](https://img.shields.io/github/license/aicccode/dance-tonight)](https://github.com/aicccode/dance-tonight/blob/main/LICENSE) [![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-4a5568)](https://github.com/aicccode/dance-tonight/releases/latest)

音楽に合わせて体を動かすフィットネスゲームであり、3Dダンス練習ツールでもあります。フィットネス動作はカメラでフォームの出来栄えを判定し、正確度とリズムでスコア化。複雑なダンスは、インストラクターを見てステップを覚え、振り付けを最後まで踊るスタイルです。画面上のVRMコーチが連続でお手本を見せ、音声が次の動きを事前に知らせます。

Windows、macOS、Linuxに対応。すべてローカルで動作し、サーバーは不要。カメラ映像があなたのPCの外に出ることはありません。

## 機能

| モード | 説明 |
|---|---|
| **今日のトレーニング** | 100日プランに沿って自動で曲を選び、その日の分量を確保。動きの密度と種類は日数とともに段階的に増え、7日ごとにリカバリーデー |
| **スピードチャレンジ** | 125 BPM以上のアップテンポな曲（DJなど）向け。1拍に1つの動き、ライフバーでスコア管理：PERFECT +3、GREAT +1、GOOD −4、MISS −14、ライフバーが空になるとチャレンジ失敗。徐々に加速するモードもあり。曲ごとにランキングあり |
| **動作練習** | 1回に1つの動きを練習。コーチが繰り返しデモを行い、画面にはリアルタイムのマッチ度バーと回数カウントを表示 |
| **モダンダンス学習** | 実写モーションキャプチャ駆動の3Dコーチ：Mixamo FBX / BVH / VRMAのモーキャプファイルを読み込んで学習。0.25〜1倍速、区切りのループ、鏡表示、ドラッグで360°回転確認、カメラとの並列比較 |
| **ダンスモード** | 27種類のダンス動作/左右バリエーション、4つの振り付け（スターライトリズム/ブロックスウィング/フローボディ/ローテーションステージ）、各4つの8カウントセクション。まずゆっくり分割練習し、その後曲に合わせて通しで披露。複雑な動きはステップごとの指導と達成度で進め、2Dのターン認識の制約を受けません |

- **カロリー推定**：「実際にヒットした動き × 動作MET × 1拍あたりの時間 × 体重 + 基礎代謝」で計算——外した動きはカロリーに計上されず、曲の長さに固定係数を掛けるよりはるかに合理的です。METテーブルは `web/js/core/moves.js`（`MOVE_MET`）と `web/js/dance/dancemoves.js`（`DANCE_MET`）にあります。
- **腹筋と体脂肪**：腹筋が見えるかどうかは体脂肪率次第で、腹筋トレだけでは局所的に脂肪は落ちません。継続的なトレーニング + ウエスト記録を。ウエスト/身長比が0.5を下回ることが、体重より信頼できる進歩のサインです（ホームの推移グラフは体重とウエストの両方を描画）。
- **ダンス動作**：基本動作にはディスコ、拍手、ハートポーズ、ヴォーグ、アームスイング、ヒップツイスト、ダブ、バウンス。上級動作にはボディウェーブ/ロール、アームウェーブ、チェストポップ、ショルダーロール、サイドステップ、クロスステップ、左右360°ターン、バックウェーブがあります。上級動作は複数拍にわたる連続キーフレームを使用し、正面・側面・背面を実際に通過しながら前後の重心移動を伴います。練習中はステップごとのヒントとデモの進行状況を表示し、カメラに背中が見えることは求めません。
- **3Dコーチ**：VRMアバターを使用し、鏡像でお手本を見せます（あなたが左足を上げれば、彼女は右足を上げる——鏡を見るのと同じ）。ビートの点でぴったりフォームが決まります。コーチウィンドウはドラッグ・拡大縮小でき、位置は記憶されます。コンボが続くと笑顔になります。
- **音声コーチ**：10種類のインターフェース言語すべてにオフライン音声パックを内蔵し、すぐに使えます：
  - 中国語は内蔵のCosyVoiceボイス「龍華」（longhua_v3.1）を使用；残りの9言語（英/西/露/日/韓/仏/独/葡/阿）はMicrosoft Edgeのニューラル音声で生成し、統一した女声で、音質は中国語と同等。全パックはリポジトリに同梱され、すぐに使えます；
  - 音声パックは `assets/tts/` にあります：`longhua_v3.1@zh/` は中国語、`edge@<言語>/` はその他の言語。設定で自分の録音に差し替えられます；
  - 開始カウントダウン「3、2、1」、各セットの冒頭で「左右交互にニーアップ」などの合図を読み上げ；
  - 各フレーズはビートポイントまでに読み終え、読み上げ中は音楽が自動的に小さくなり；
  - 途中で「もう半分だ」「コンボ途切れず」などの励ましも。ダンスモードでは各動きの名前をコールします（「左手指天」「左へスイング」…）。
- 台詞は `web/js/core/cue_texts.js` にあります。中国語以外の9パックは `python3 scripts/gen_voices_edge.py` で再生成できます（不足分のみ自動補完）。設定から自分の録音をアップロードして現在の言語の音声を差し替えることもできます。
- **ブラインド練習モード**：各動きで「左」「右」をコールし、ビートポイントに合図音。ヘッドフォンを着けて目を閉じたままでも練習できます。
- **ビート解析**：Beat This!（ISMIR 2024のビート認識モデル、int8量子化、22MB）を内蔵し、バックグラウンドWorkerで動作、1曲あたり約8秒。49曲のテスト楽曲で：
  - テンポ識別は48曲正解（librosaは約半分だけで、遅い曲が頻繁に2倍速と誤認識されがち）；
  - ビート位置はオリジナルのPyTorchモデルとの一致度 F = 0.995。
  - モデルのロードに失敗した場合は、内蔵の純JSビートアルゴリズムへ自動的に切り替わります。

## 動作

**フィットネス動作**（アンロックレベル順）：

| レベル | 動作 | 主な鍛え部位 |
|---|---|---|
| 1 | 🙌 両手を挙げる · 👊 左/右パンチ | 有酸素、肩 |
| 1 | 🍑 スクワット | 脚・お尻（膝の角度で深さを判定） |
| 1 | 🦵 左/右ニーアップ · 🤸 つま先タッチ | 腹筋、後鎖 |
| 2 | ⭐ ジャッキングジャンプ | 有酸素 |
| 2 | ✖️ 左膝→右肘 / 右膝→左肘 | 腹斜筋 |
| 2 | 🦵 左/右サイドニーアップ · 🦶 左/右フロントキック | 腹斜筋、お尻、体幹安定 |
| 3 | 🌙 左/右サイドベンド（キープ可） | 側腹 |

**ダンス動作**（27種類の動作/左右バリエーション）：ディスコ指天、胸元で拍手、両手でハート、ファッションポーズ、左右アームスイング、ヒップツイスト、ダブ、バウンスリズム、さらにボディウェーブ、ボディサークル、左右アームウェーブ、チェストポップ、ショルダーロール、左右サイドステップ、左右クロスステップ、左右ターン、バックウェーブ。

ジャズ/モダンダンスをもっと学びたい場合：[Mixamo](https://www.mixamo.com/) で Jazz / Contemporary / Dance を検索し、ダウンロード形式は **FBX Binary**、Skin は **Without Skin** を選択してから、「ダンス → モーキャプファイルをインポート」から取り込みます（一度に何十ファイルでも選択可能で、順次変換され、壊れたファイルは別途表示され他のファイルには影響しません）。インポート時に骨格（Mixamo、CMU、主要なBVH、VRMA）を自動認識し、座標軸と向きを補正、A/Tポーズの差を整列、キャプチャのジッターを除去し、冒頭と末尾の静止区間をカットします。変換後のデータはローカルデータディレクトリの `dances/` に保存されます。

**自分で振り付けを作る**：「ダンス → マイ振り付け → 新規振り付け」で、右側の動作ライブラリから動きをシーケンスにドラッグ（2つの動きの間にドロップするとそこに挿入）、または動きをクリックして選択中の動きの後ろに追加。シーケンス内の動きはドラッグで順序変更、Deleteキーで削除、ワンクリックで左右ミラー反転も可能です。各動きはそれぞれの長さで時間を占有：通常の動きは1拍、ターン/ウェーブなどはそれぞれの拍数、モーキャプ（インポートしたものも内蔵モダンダンスも）は全体を原速で再生し、次の動きは直後の拍から始まります。披露時は曲を1つ選び、最初の動きから最後の動きの終わりまで踊ります（音楽もそれに合わせてフェードアウト）。セクション練習ではシーケンスを約8拍ごとに自動分割します。内蔵の振り付けは「コピーしてアレンジ」を起点にできます。振り付けはデータディレクトリの `data/data.json` に保存されます。

**上級振り付け**：「フローボディ」はボディライン、アームウェーブ、胸と肩のアイソレーションを重視。「ローテーションステージ」は横方向のステップ、完全なターン、背面コンビネーションを重視。複数拍の動きは2拍または4拍で完全にお手本を見せ、アニメーション途中で切り替えません。

## ダウンロードとインストール

コードを書かなくても使えます。[Releases](https://github.com/aicccode/dance-tonight/releases/latest) からお使いのプラットフォームのインストーラーをダウンロードし、ダブルクリックするだけです。アカウント登録もオンライン認証も不要です。

| プラットフォーム | ファイル | インストール方法 |
|---|---|---|
| Windows 10 / 11 (x64) | `Dance.Tonight.Setup.*.exe` | 実行するだけ。初回は SmartScreen が「不明な発行元」と表示するので「詳細情報 → 実行」を選びます |
| macOS (Apple シリコン) | `Dance.Tonight-*-arm64.dmg` | アイコンを「アプリケーション」へドラッグ。公証を受けていないため、初回は右クリック →「開く」 |
| macOS (Intel) | `Dance.Tonight-*.dmg` | 上と同じ |
| Linux (x64) | `Dance.Tonight-*.AppImage` | `chmod +x` して実行。FUSE が無い場合は `libfuse2` を入れてください |

コード署名証明書を取得していないため、Windows と macOS では「不明な開発元」という警告が出ます。ソースはすべてこのリポジトリにあります。確認するか、次の節の手順でソースからビルドしてください。

## ソースから実行（3プラットフォーム共通）

Node.js 20 以上が必要です。

```bash
npm install      # 依存関係は npmmirror 経由（.npmrc 参照）、インストール後に MediaPipe/three.js/onnxruntime を自動で web/vendor にコピー
npm start
```

`web/vendor/` は生成物でリポジトリには含まれません。`npm install` の後 `scripts/vendor.mjs` が再構築し、ブラウザ用ライブラリは `node_modules` から、ポーズモデルは `assets/models/` からコピーします。インストール時にダウンロードは発生しません。

`assets/` ディレクトリには内蔵リソースが入っており、パッケージング時に一緒に同梱されます。リポジトリには**最小検証パック**のみを同梱しています（大容量/個人リソースはリポジトリに入れません）：

| パス | 内容 |
|---|---|
| `assets/models/beat_this_final0.int8.onnx` | ビートモデル（Beat This! int8、MIT、NOTICE 参照） |
| `assets/avatars/RealMaster.vrm` `SportGirl.vrm` | 内蔵コーチアバター（各モデルのライセンスは NOTICE 参照） |
| `assets/dances/*.json` | 内蔵モーキャプダンス3本 |
| `assets/tts/longhua_v3.1@zh/` `edge@<言語>/` | オフライン音声パック：全10言語がリポジトリに同梱。設定で自分の録音に差し替え可能 |

**最小検証フロー**：`npm install && npm start` → 楽曲ライブラリ → ファイル追加 → 手持ちの曲 を選択 → ビート解析の完了を待つ → ホームでトレーニング開始。または「ダンス」ページで内蔵モーキャプを直接フォロー。

**追加リソース**：
- VRMコーチアバター：[VRoid Hub](https://hub.vroid.com/) で好きなアバターをダウンロードし（各モデルのライセンス条項に注意）、「設定 → コーチアバター」からインポート；
- モーキャプファイル：アプリ内の「ダンス」ページに [Mixamo](https://www.mixamo.com/) への入口があり、ダウンロードは **FBX Binary + Without Skin** を選んで一括インポート；
- 楽曲：自分でインポート。同一内容は1部のみ保存します。

## デバイス間データ移行

アプリはネット接続・登録不要で、すべてのデータはローカルに保存されます。データを別のデバイスへ移すには「設定 → データ → データパッケージのエクスポート」で `.dtx` ファイルを生成します：項目別チェック（トレーニング / 体重とウエスト / マイ振り付け / 取り込んだモーキャプ / 楽曲コピー / ビート解析 / 設定）、gzip 圧縮、SM9 暗号化（SM4 モード）。鍵はパスフレーズのみから導出され（8 文字以上）、パスフレーズはファイルに書かれず外部にも送られません。インポートは差分のみ：内容で重複を判定し、既存の記録はそのまま、足りない分だけ追加します。旧バージョンの「アカウント + パスフレーズ」形式のパッケージもそのままインポートできます。

## 初めて使うとき

1. **楽曲ライブラリ → フォルダごと追加**：音楽ディレクトリを選択すると、バックグラウンドでビート解析が始まります。楽曲はアプリのデータディレクトリにコピーされ（同一内容は1部のみ）、元ファイルはその後削除や移動が可能です。以前インポートした楽曲は起動時に自動でコピーを補完します。
2. 旧バージョンからの移行：**設定 → データ** に「旧データをインポート」（`legacy.json`：トレーニング記録・体重・プラン開始日、重複は自動で除外）と「ビート解析パッケージをインポート」（`beat_pack.json`：内容の指紋で照合するため該当曲は再解析不要）があります。
3. 自分の声を使いたい場合は、**設定 → 音声コーチ** でセリフのテキストと同じ名前の録音ファイルをアップロードすると、現在の言語の音声を差し替えられます。内蔵パックはワンクリックで復元できます。
4. まず **動作練習** で各動きを一通り練習してから、ホームに戻ってトレーニングを始めましょう。

配置の推奨：人からカメラまで2.5〜3メートル、全身がフレームに収まるように（足首まで含む）、光は正面から。各曲の開始前に直立し、両手を自然に下ろして約1秒でキャリブレーションが完了します。

| キー | 機能 |
|---|---|
| スペース | キャリブレーションをスキップ / 一時停止 |
| Esc | この曲を終了 |

| OS | 場所 |
|---|---|
| Windows | `%APPDATA%\Dance Tonight\` |
| macOS | `~/Library/Application Support/Dance Tonight/` |
| Linux | `~/.config/Dance Tonight/` |

ディレクトリ内の `data/data.json` には進捗・成績・体重が、`data/analysis/` には各曲のビート解析が、`music/` にはインポートした楽曲のコピーが、`tts/`・`avatars/`・`dances/` には自分で生成した音声・インポートしたアバター・インポートしたモーキャプダンスが保存されます。インポート後は元ファイルを削除しても構いません。バックアップや機種変更時はディレクトリ全体をコピーしてください。楽曲ライブラリで曲を削除すると、`music/` 内のコピーも一緒に削除されます（元のファイルには触れません）。

## 開発

```bash
npm test                          # ユニットテストとカバレッジ
python3 scripts/gen_voices_edge.py  # 任意：残り9言語の音声パックを再生成（pip install edge-tts）
npm run test:coach                # 基本ダンス動作14種 × 3 VRM、実際の関節を判定器に入力
npm run test:motion               # 上級動作13種 × 5フェーズ × 3 VRM、検証とスクリーンショット
npm run test:mocap                # モーキャプダンス × 3 VRM のレンダリング検査 + 学習UI/インポートフロー
npm run e2e                       # Electron 全フロー + 上記2種類のコーチ回帰
DT_E2E_EXE=dist/linux-unpacked/dance-tonight npm run e2e   # パッケージ後のプログラムをテスト
node e2e/pose_gallery.mjs         # すべてのフィットネス/ダンスポーズの比較図（連続動作は中間フレーム）
node e2e/coach_motion.mjs /tmp/dt-motion  # 5フェーズ動作の接触表
node scripts/eval_beats.mjs <楽曲ディレクトリ> <リファレンス結果.json> beatthis   # ビート精度評価
```

ディレクトリ構成：

| ディレクトリ | 内容 |
|---|---|
| `electron/` | メインプロセス：ウィンドウ、`app://` プロトコル（クロスオリジン分離、WASMマルチスレッドに必要）、プロセス間呼び出し、ローカルJSONストレージ、音声パック管理、VRM管理 |
| `web/js/core/` | 動作カタログ、100日プラン、譜面生成、音声台詞。メインプロセスとUIで共用 |
| `web/js/analysis/` | 純JSビートアルゴリズム、Beat This! の前処理と後処理、解析Worker |
| `web/js/coach/` | 3Dコーチ：three.js + three-vrm、ポーズとタイムカーブ |
| `web/js/voice/` | 音声合図のタイミング計画（純関数）と Web Audio 再生 |

## 既知の制限

- 動作判定の閾値は合成ポーズでのみテストされており、**まだ実人での較正は行っていません**。ある動きが正しくできているのに判定が満点にならない場合は、報告するか `web/js/judge.js` の `MATCHERS` を調整してください。
- 認識は2D正面視点のみで、体の前後方向や背中側の動きは正確に見えません。そのため**フィットネス動作は正面から検出しやすいポーズのみを採用し、ターン・背面・depth動作はダンスのガイド学習にのみ使用**し、関節マッチングのスコアリングには依存しません。
- 基本ダンス動作の判定閾値は合成ポーズでのみ較正されています。実人が踊ったときに採点が甘い/厳しいと感じたら、`web/js/dance/dancemoves.js` の `DANCE_MATCHERS` を調整してください。上級ガイド動作はフォロー完了を基準とし、この数値を実人の踊りの正確さとしては扱いません。
- Windows版とmacOS版は現在Linux上でのパッケージングのみで、**実機での動作テストはまだ行っていません**。
