# Dance Tonight · 100일 복근 지방 연소 플랜(데스크톱 버전)

[![CI](https://github.com/aicccode/dance-tonight/actions/workflows/ci.yml/badge.svg)](https://github.com/aicccode/dance-tonight/actions/workflows/ci.yml) [![Release](https://img.shields.io/github/v/release/aicccode/dance-tonight?sort=semver)](https://github.com/aicccode/dance-tonight/releases/latest) [![License](https://img.shields.io/github/license/aicccode/dance-tonight)](https://github.com/aicccode/dance-tonight/blob/main/LICENSE) [![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-4a5568)](https://github.com/aicccode/dance-tonight/releases/latest)

음악에 맞춰 움직이는 피트니스 게임이자 3D 댄스 따라하기 도구입니다. 피트니스 동작은 카메라로 자세의 완성도를 판단해 정확도와 리듬으로 점수를 매기고, 복잡한 댄스는 강사를 보고 스텝을 익히며 안무를 끝까지 따라추는 방식입니다. 화면의 VRM 코치가 연속으로 시범을 보여 주고, 음성이 다음 동작을 미리 알려 줍니다.

Windows, macOS, Linux를 지원합니다. 전부 로컬에서 실행되며 서버가 필요 없고, 카메라 화면은 여러분의 PC 밖으로 나가지 않습니다.

## 기능

| 모드 | 설명 |
|---|---|
| **오늘의 훈련** | 100일 플랜에 따라 노래를 자동으로 골라 그날의 분량을 채웁니다. 동작의 밀도와 종류는 날수에 따라 점점 올라가고, 7일마다 회복일입니다 |
| **스피드 챌린지** | 125 BPM 이상의 빠른 노래(DJ 등)에 적합합니다. 한 박자에 동작 하나, 체력 바로 점수를 매깁니다: PERFECT +3, GREAT +1, GOOD −4, MISS −14, 체력 바가 비면 챌린지 실패. 점점 빨라지는 모드도 있고, 노래마다 자체 랭킹이 있습니다 |
| **동작 연습** | 한 번에 동작 하나씩 연습합니다. 코치가 반복해서 시범을 보이고, 화면에 실시간 일치도 바와 횟수 집계가 표시됩니다 |
| **현대무용 배우기** | 실사 모션 캡처 기반 3D 코치: Mixamo FBX / BVH / VRMA 모캡 파일을 가져와 따라 배웁니다. 0.25~1배속, 구간 반복, 좌우 반전, 드래그로 360° 돌려 보기, 카메라 화면과 나란히 비교 |
| **댄스 모드** | 27개 댄스 동작/좌우 변형, 4세트 안무(스타라이트 리듬/블록 스윙/플로우 바디/로테이션 스테이지), 각 세트마다 4개의 8박 구간. 먼저 느린 속도로 구간별 따라 하고, 이후 노래를 골라 처음부터 끝까지 공연합니다. 복잡한 동작은 단계별 학습과 완성도로 진행되며 2D 회전 인식의 제약을 받지 않습니다 |

- **칼로리 추정**: "실제로 적중한 동작 × 동작 MET × 박자당 시간 × 체중 + 기초 대사량"으로 계산합니다——놓친 동작은 칼로리에 포함되지 않아, 노래 전체 길이에 고정 계수를 곱하는 방식보다 훨씬 합리적입니다. MET 표는 `web/js/core/moves.js`(`MOVE_MET`)와 `web/js/dance/dancemoves.js`(`DANCE_MET`)에 있습니다.
- **복근과 체지방**: 복근이 보이는지는 체지방률에 달려 있으며, 복근 운동만으로 국소적인 지방 감소는 일어나지 않습니다. 꾸준한 훈련 + 허리둘레 기록을 지속하세요. 허리둘레/신장 비율이 0.5 아래로 내려가는 것이 체중보다 더 신뢰할 수 있는 진전 신호입니다(홈 화면의 추이 그래프는 이제 체중과 허리둘레를 함께 그립니다).
- **댄스 동작**: 기본 동작에는 디스코, 박수, 하트 포즈, 보그, 팔 흔들기, 엉덩이 티스팅, 더브, 바운스가 있고, 상급 동작에는 바디 웨이브/롤, 암 웨이브, 체스트 팝, 숄더 롤, 사이드 스텝, 크로스 스텝, 좌우 360° 회전 및 등 뒤 웨이브가 있습니다. 상급 동작은 여러 박자에 걸친 연속 키프레임을 사용해 실제로 정면·측면·후면을 지나가며 앞뒤 무게 중심 이동을 동반합니다. 연습 시 단계별 힌트와 시범 진행 상황을 표시하며, 카메라가 뒷모습을 인식할 것을 요구하지 않습니다.
- **3D 코치**: VRM 아바타를 사용하며 거울처럼 좌우 반전 시범을 보입니다(당신이 왼쪽 다리를 들면 그녀는 오른쪽 다리를 들어, 거울을 보는 것과 같습니다). 박자 포인트에 정확히 동작이 완성됩니다. 코치 창은 드래그와 크기 조절이 가능하고 위치가 기억됩니다. 콤보가 이어지면 웃습니다.
- **음성 코치**: 10개 인터페이스 언어 모두 오프라인 음성 패키지를 내장해 바로 사용할 수 있습니다:
  - 중국어는 내장 CosyVoice 보이스 "용화"(longhua_v3.1)를 사용하고, 나머지 9개 언어(영/서/러/일/한/프/독/포/아)는 Microsoft Edge 신경망 음성으로 생성하며, 통일된 여성 음성으로 음질은 중국어와 비슷합니다. 모든 팩은 저장소에 포함되어 바로 사용할 수 있습니다;
  - 음성 패키지는 `assets/tts/`에 있습니다: `longhua_v3.1@zh/`는 중국어, `edge@<언어>/`는 기타 언어. 설정에서 현재 언어의 음성을 직접 녹음한 파일로 교체할 수 있습니다;
  - 시작 카운트다운 "셋, 둘, 하나", 세트 시작 시 "양쪽 번갈아 무릎 들기" 같은 안내 멘트;
  - 모든 문장은 박자 포인트 전에 끝까지 읽히며, 읽는 동안 음악이 자동으로 작아집니다;
  - 중간에 "절반이 지났어요" "콤보 끊기지 않아요" 같은 격려도 합니다. 댄스 모드에서는 모든 동작의 이름을 불러 줍니다("왼손 하늘 가리기", "왼쪽으로 팔 흔들기"…).
- 대사 텍스트는 `web/js/core/cue_texts.js`에 있습니다. 중국어를 제외한 9개 팩은 `python3 scripts/gen_voices_edge.py`로 다시 생성할 수 있습니다(누락된 것만 자동 보완). 설정에서 직접 녹음을 업로드해 현재 언어의 음성을 교체할 수도 있습니다.
- **블라인드 연습 모드**: 모든 동작마다 "왼쪽" "오른쪽"을 불러 주고 박자 포인트에 신호음이 납니다. 헤드폰을 끼고 눈을 감은 채로도 따라 할 수 있습니다.
- **비트 분석**: Beat This!(ISMIR 2024 비트 인식 모델, int8 양자화, 22MB)를 내장하고 백그라운드 Worker에서 실행되며 노래당 약 8초 걸립니다. 테스트곡 49곡 기준:
  - 템포 인식 48곡 정답(librosa는 절반 정도만 맞히고 느린 노래가 자주 2배속으로 오인식됨);
  - 비트 위치는 원본 PyTorch 모델과의 일치도 F = 0.995.
  - 모델 로드에 실패하면 내장된 순수 JS 비트 알고리즘으로 자동 전환합니다.

- **온라인 음악**: 라이브러리에서 바로 로열티 프리 음악을 검색합니다(Openverse가 Freesound·Jamendo·Wikimedia Commons 등을 모음, 계정 불필요). 상업적 사용이 가능한 라이선스(CC0 / CC-BY / CC-BY-SA)만 반환되며, 미리 듣고 한 번의 클릭으로 가져오면 비트 분석이 자동으로 시작됩니다.

**댄스 동작**(27개 동작/좌우 변형): 디스코 하늘 가리기, 가슴 앞 박수, 양손 하트, 패션 포즈, 좌우 팔 흔들기, 엉덩이 티스팅, 더브, 바운스 리듬, 그리고 바디 웨이브, 바디 서클, 좌우 암 웨이브, 체스트 팝, 숄더 롤, 좌우 사이드 스텝, 좌우 크로스 스텝, 좌우 회전과 등 뒤 웨이브.

재즈/현대무용을 더 배우고 싶다면: [Mixamo](https://www.mixamo.com/)에서 Jazz / Contemporary / Dance를 검색하고, 다운로드 형식은 **FBX Binary**, Skin은 **Without Skin**으로 선택한 뒤 「댄스 → 모캡 파일 가져오기」에서 가져옵니다(한 번에 수십 개 파일을 선택할 수 있고 하나씩 변환되며, 손상된 파일은 별도로 표시되어 다른 파일에 영향을 주지 않습니다). 가져올 때 골격(Mixamo, CMU, 주요 BVH, VRMA)을 자동 인식하고 좌표축과 방향을 보정하며 A/T 포즈 차이를 정렬하고 캡처 떨림을 제거하며 앞뒤 정지 구간을 잘라 냅니다. 변환된 데이터는 로컬 데이터 디렉터리의 `dances/`에 저장됩니다.

**직접 안무 만들기**: 「댄스 → 내 안무 → 새 안무」에서 오른쪽 동작 라이브러리의 동작을 시퀀스로 드래그합니다(두 동작 사이에 놓으면 그 자리에 삽입)하거나, 동작을 클릭해 선택된 동작 뒤에 바로 추가할 수도 있습니다. 시퀀스의 동작은 드래그로 순서 조정, Delete 키로 삭제, 원클릭 좌우 미러 반전이 가능합니다. 각 동작은 자신의 길이만큼 시간을 차지합니다: 일반 동작은 1박, 회전/웨이브 등은 각자의 박자 수, 모캡(가져온 것과 내장 현대무용 모두)은 전체를 원래 속도로 재생하고 다음 동작은 바로 이어지는 박자부터 시작합니다. 공연할 때는 노래를 하나 골라 첫 동작부터 마지막 동작이 끝날 때까지 춥니다(음악도 이에 맞춰 페이드아웃). 구간 연습은 시퀀스를 약 8박 단위로 자동 분할합니다. 내장 안무는 「복사 후 편집」으로 시작점 삼아 활용할 수 있습니다. 안무는 데이터 디렉터리의 `data/data.json`에 저장됩니다.

**상급 안무**: 「플로우 바디」는 바디 라인, 암 웨이브, 가슴·어깨 아이솔레이션에 중점을 둡니다. 「로테이션 스테이지」는 측면 스텝, 완전한 회전, 등 뒤 조합에 중점을 둡니다. 여러 박자 동작은 2박 또는 4박으로 온전히 시범 보이며 애니메이션 중간에 전환하지 않습니다.

## 다운로드 및 설치

코딩 없이 바로 쓸 수 있습니다. [Releases](https://github.com/aicccode/dance-tonight/releases/latest)에서 사용하는 플랫폼의 설치 파일을 내려받아 실행하면 됩니다. 가입도, 온라인 인증도 필요 없습니다.

| 플랫폼 | 파일 | 설치 방법 |
|---|---|---|
| Windows 10 / 11 (x64) | `Dance.Tonight.Setup.*.exe` | 실행합니다. 처음 실행하면 SmartScreen이 "알 수 없는 게시자"를 표시하니 "추가 정보 → 실행"을 누르세요 |
| macOS (Apple 실리콘) | `Dance.Tonight-*-arm64.dmg` | 아이콘을 "응용 프로그램"으로 끌어다 놓습니다. 공증을 받지 않았으므로 처음에는 우클릭 → 열기 |
| macOS (Intel) | `Dance.Tonight-*.dmg` | 위와 같습니다 |
| Linux (x64) | `Dance.Tonight-*.AppImage` | `chmod +x` 후 실행합니다. FUSE가 없으면 `libfuse2`를 설치하세요 |

코드 서명 인증서가 없어 Windows와 macOS에서 "알 수 없는 개발자" 경고가 뜹니다. 소스는 모두 이 저장소에 있으니 직접 확인하거나 다음 절대로 소스에서 빌드하세요.

## 소스에서 실행하기(3개 플랫폼 공통)

Node.js 20 이상이 필요합니다.

```bash
npm install      # 의존성은 npmmirror 경유(.npmrc 참조), 설치 후 MediaPipe/three.js/onnxruntime을 web/vendor로 자동 복사
npm start
```

`web/vendor/`는 생성물이라 저장소에 들어가지 않습니다. `npm install` 후 `scripts/vendor.mjs`가 다시 만들며, 브라우저 라이브러리는 `node_modules`에서, 포즈 모델은 `assets/models/`에서 복사합니다. 설치 과정에서 내려받는 것은 없습니다.

`assets/` 디렉터리에는 내장 리소스가 들어 있으며 패키징 시 함께 포함됩니다. 저장소에는 **최소 검증 패키지만** 내장합니다(대용량/개인 리소스는 저장소에 넣지 않음):

| 경로 | 내용 |
|---|---|
| `assets/models/beat_this_final0.int8.onnx` | 비트 모델(Beat This! int8, MIT, NOTICE 참조) |
| `assets/avatars/RealMaster.vrm` `SportGirl.vrm` | 내장 코치 아바타(각 모델 라이선스는 NOTICE 참조) |
| `assets/dances/*.json` | 내장 모캡 댄스 3개 |
| `assets/tts/longhua_v3.1@zh/` `edge@<언어>/` | 오프라인 음성 패키지: 10개 언어 모두 저장소에 포함되어 배포되며, 설정에서 직접 녹음으로 교체 가능 |
| `assets/music/*.mp3` | 기본 포함된 두 곡(CC BY 3.0, 크레딧은 `assets/music/CREDITS.md`)으로, 첫 실행 시 라이브러리에 복사되고 분석됩니다. 온라인 검색은 Openverse에 의존하는데 일부 네트워크(중국 본토 등)에서는 접속할 수 없어 오프라인에서도 바로 사용할 수 있게 했습니다 |

**최소 검증 절차**: `npm install && npm start` → 곡 라이브러리 → 기본 포함된 두 곡은 이미 분석되어 있습니다. 직접 가진 곡은 「파일 추가」로 → 홈에서 훈련 시작. 또는 「댄스」 페이지에서 내장 모캡을 바로 따라 하기.

**추가 리소스**:
- VRM 코치 아바타: [VRoid Hub](https://hub.vroid.com/)에서 마음에 드는 아바타를 내려받고(각 모델의 라이선스 조항에 유의) 「설정 → 코치 아바타」에서 가져오기;
- 모캡 파일: 앱 내 「댄스」 페이지에 [Mixamo](https://www.mixamo.com/) 입구가 있으며, 다운로드는 **FBX Binary + Without Skin**으로 선택해 일괄 가져오기;
- 노래: 직접 가져오며, 동일 내용은 한 벌만 저장합니다.

## 기기 간 데이터 이전

앱은 네트워크 연결이나 회원가입 없이 모든 데이터를 로컬에 저장합니다. 데이터를 다른 기기로 옮기려면 「설정 → 데이터 → 데이터 패키지 내보내기」로 `.dtx` 파일을 만듭니다: 항목별 선택(훈련 / 체중과 허리둘레 / 내 안무 / 가져온 모캡 / 노래 사본 / 비트 분석 / 설정), gzip 압축, SM9 암호화(SM4 모드). 키는 암호문구만으로 유도되며(8자 이상), 암호문구는 파일에 기록되지 않고 외부로 전송되지도 않습니다. 가져오기는 증분 방식이라 내용 기준으로 중복을 걸러 기존 기록은 그대로 두고 빠진 것만 추가합니다. 예전 버전의 「계정 + 암호문구」 패키지도 그대로 가져올 수 있습니다.

## 처음 사용할 때

1. **곡 라이브러리 → 폴더 전체 추가**: 음악 디렉터리를 선택하면 백그라운드에서 비트 분석이 시작됩니다. 노래는 앱 데이터 디렉터리에 한 벌 복사되고(동일 내용은 한 벌만 저장), 이후 원본 파일은 삭제하거나 옮겨도 됩니다. 이전에 가져온 노래는 시작 시 자동으로 복사를 보완합니다.
2. 이전 버전에서 옮겨오는 경우: **설정 → 데이터**에 「이전 데이터 가져오기」(`legacy.json`: 훈련 기록·체중·계획 시작일, 중복은 자동 제외)와 「비트 분석 패키지 가져오기」(`beat_pack.json`: 내용 지문으로 매칭되어 해당 곡은 다시 분석하지 않음)가 있습니다.
3. 자신의 목소리를 쓰고 싶다면 **설정 → 음성 코치**에서 대사 텍스트와 같은 이름의 녹음 파일을 업로드하세요. 현재 언어의 음성이 교체되며, 내장 팩은 한 번의 클릭으로 복원됩니다.
4. 먼저 **동작 연습**에서 각 동작을 한 번씩 연습한 뒤 홈으로 돌아와 훈련을 시작하세요.

배치 권장: 사람은 카메라에서 2.5~3미터 떨어지고, 전신이 화면에 들어오도록(발목까지 포함) 하며, 빛은 정면에서 비춥니다. 각 노래 시작 전에 똑바로 서서 양손을 자연스럽게 내린 채 약 1초 동안 캘리브레이션을 완료합니다.

## 알려진 한계

- 동작 판정 기준치는 합성 포즈에서만 테스트되었으며 **아직 실제 사람으로 보정하지 않았습니다**. 어떤 동작을 제대로 했는데도 판정이 만점이 나오지 않으면 알려 주시거나 `web/js/judge.js`의 `MATCHERS`를 조정하세요.
- 인식은 2D 정면 시점만 사용해 몸의 앞뒤 방향과 등 쪽 동작을 정확히 볼 수 없습니다. 따라서 **피트니스 동작은 정면에서 감지하기 쉬운 포즈만 채택하고, 회전·후면·depth 동작은 댄스 안내 학습에만 사용**하며 관절 매칭 점수에 의존하지 않습니다.
- 기본 댄스 동작의 판정 기준치도 합성 포즈에서만 보정되었습니다. 실제로 출 때 채점이 너무 느슨하거나 엄격하다고 느껴지면 `web/js/dance/dancemoves.js`의 `DANCE_MATCHERS`를 조정하세요. 상급 안내 동작은 따라 하기 완료를 기준으로 하며, 이 수치를 실제 춤 자세의 정확성으로 취급하지 않습니다.
- Windows와 macOS 버전은 현재 Linux에서만 패키징해 보았으며 **실기에서 실행 테스트를 아직 하지 않았습니다**.
