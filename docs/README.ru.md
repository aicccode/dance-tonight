# Dance Tonight · 100-дневный план на пресс и жиросжигание (десктоп)

[![CI](https://github.com/aicccode/dance-tonight/actions/workflows/ci.yml/badge.svg)](https://github.com/aicccode/dance-tonight/actions/workflows/ci.yml) [![Release](https://img.shields.io/github/v/release/aicccode/dance-tonight?sort=semver)](https://github.com/aicccode/dance-tonight/releases/latest) [![License](https://img.shields.io/github/license/aicccode/dance-tonight)](https://github.com/aicccode/dance-tonight/blob/main/LICENSE) [![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-4a5568)](https://github.com/aicccode/dance-tonight/releases/latest)

Фитнес-игра под музыку и одновременно инструмент 3D-тренировок с танцами. Фитнес-упражнения камера оценивает по тому, насколько точно вы выполняете позицию, выставляя баллы за точность и ритм; сложные танцы построены на слежении за тренером, разучивании шагов и прохождении полной хореографии. VRM-тренер на экране показывает движения непрерывно, а голос заранее подсказывает следующее упражнение.

Поддерживаются Windows, macOS и Linux. Всё работает локально, сервер не нужен, изображение с камеры не покидает ваш компьютер.

## Возможности

| Режим | Описание |
|---|---|
| **Тренировка на сегодня** | Автоматически подбирает песни по 100-дневному плану, чтобы набрать нужную длительность дня. Плотность и разнообразие упражнений постепенно растут с днями; каждый 7-й день — день восстановления |
| **Скоростной челлендж** | Для быстрых песен выше 125 BPM (электронная музыка и т.п.). Одно движение на каждый бит, счёт через полосу здоровья: PERFECT +3, GREAT +1, GOOD −4, MISS −14; если полоса опустеет — челлендж провален. Можно включить постепенное ускорение; у каждой песни свой рейтинг |
| **Обучение упражнениям** | Отработка одного упражнения за раз. Тренер показывает движение по кругу, на экране — полоса совпадения в реальном времени и счётчик повторений |
| **Разучивание современной хореографии** | 3D-тренер на основе реальной захваченной пластики: импортируйте файлы моушен-капчера Mixamo FBX / BVH / VRMA и учитесь повторять. Скорость 0,25–1×, повторы по секциям, зеркальный режим, перетаскивание для осмотра движения на 360°, параллельное сравнение с камерой |
| **Танцевальный режим** | 27 танцевальных движений/вариантов «лево-право», четыре постановки (Пульс Звёзд / Качание Квартала / Струящаяся Линия / Вращающаяся Сцена), в каждой 4 секции по 8 счётов. Сначала медленно отрабатывайте по секциям, затем выберите песню для полного выступления; сложные движения разбираются по шагам с учётом выполнения, без ограничений 2D-распознавания поворотов |

- **Оценка калорий**: считается как «фактически выполненные движения × MET движения × секунд на бит × вес тела + базовый расход» — пропущенные движения не сжигают калорий, что куда разумнее умножения длительности всей песни на фиксированный коэффициент. Таблицы MET лежат в `web/js/core/moves.js` (`MOVE_MET`) и `web/js/dance/dancemoves.js` (`DANCE_MET`).
- **Пресс и жир**: виден ли пресс, зависит от процента жира; упражнения на пресс не сжигают жир локально. Продолжайте тренировки + записывайте объём талии: соотношение талии к росту ниже 0,5 — более надёжный сигнал прогресса, чем вес (график трендов на главной теперь строит и вес, и талию).
- **Танцевальные движения**: базовые включают диско, хлопок, «сердечко» пальцами, вог, махи руками, скручивание бёдер, даб и баунс; продвинутые — body wave/roll корпуса, волну руками, грудной поп, ролл плечами, приставной шаг, кросс-шаг, полные повороты на 360° влево/вправо и волну спиной к камере. Продвинутые движения используют непрерывные ключевые кадры на несколько битов, действительно проходя через фас, профиль и спину со смещением веса вперёд-назад; при отработке показываются пошаговые подсказки и прогресс демонстрации, распознавание спины камерой не требуется.
- **3D-тренер**: использует VRM-аватар и зеркальный показ (вы поднимаете левую ногу — она правую, как в зеркале), попадая в позицию точно на бит. Окно тренера можно перетаскивать и масштабировать, положение запоминается. При комбо она улыбается.
- **Голосовой тренер**: все 10 языков интерфейса снабжены встроенными офлайн-голосовыми пакетами и работают сразу из коробки:
  - В китайском — встроенный голос CosyVoice «Лунхуа» (longhua_v3.1); остальные 9 языков (английский / испанский / русский / японский / корейский / французский / немецкий / португальский / арабский) генерируются нейроголосами Microsoft Edge — единый женский голос, по качеству сравнимый с китайским; все пакеты распространяются с репозиторием и готовы сразу;
  - Голосовые пакеты лежат в `assets/tts/`: `longhua_v3.1@zh/` — китайский, `edge@<язык>/` — остальные языки; в настройках пакет своего языка можно заменить собственными записями;
  - Отсчёт «три, два, один» на старте; каждая серия начинается с подсказок вроде «попеременные подъёмы колен»;
  - Каждая фраза заканчивается до её бита, музыка автоматически приглушается во время речи;
  - По ходу тренировки звучат подбадривания вроде «уже половина» или «не рви комбо»; в танцевальном режиме каждое движение называется по имени («палец в небо», «мах влево»…).
- Тексты реплик живут в `web/js/core/cue_texts.js`; 9 не-китайских пакетов пересобираются через `python3 scripts/gen_voices_edge.py` (досоздаются только недостающие). Свой голос можно загрузить в настройках — он заменит голос текущего языка.
- **Режим тренировки вслепую**: каждое движение озвучивается как «лево» или «право», на бите звучит сигнал. Можно тренироваться в наушниках с закрытыми глазами.
- **Анализ ритма**: встроенный Beat This! (модель определения битов с ISMIR 2024, int8-квантование, 22MB), работает в фоновом Worker, около 8 секунд на песню. На 49 тестовых песнях:
  - Темп верно определён у 48 (librosa угадала лишь около половины, часто принимая медленные песни за двойной темп);
  - Позиции битов совпадают с оригинальной PyTorch-моделью с F = 0,995.
  - Если модель не загрузилась, автоматически используется встроенный алгоритм на чистом JS.

## Упражнения

**Фитнес-упражнения** (по уровню разблокировки):

| Уровень | Упражнения | Основные мышцы |
|---|---|---|
| 1 | 🙌 Руки вверх · 👊 Удары левой/правой | Кардио, плечи |
| 1 | 🍑 Приседание | Ноги и ягодицы (глубина — по углу колена) |
| 1 | 🦵 Подъёмы колена левой/правой · 🤸 Наклон к носкам | Пресс, задняя цепочка |
| 2 | ⭐ Джампинг-джеки | Кардио |
| 2 | ✖️ Левое колено к правому локтю / правое колено к левому локтю | Косые мышцы живота |
| 2 | 🦵 Боковые подъёмы колена левой/правой · 🦶 Махи вперёд левой/правой | Косые, ягодицы, стабилизация кора |
| 3 | 🌙 Боковые наклоны влево/вправо (можно с задержкой) | Боковой пресс |

**Танцевальные движения** (27 движений/вариантов «лево-право»): диско — палец в небо, хлопок перед грудью, «сердечко» пальцами, модная поза, махи руками влево-вправо, скручивание бёдер, даб, ритмичный баунс, а также волна корпусом, круг корпусом, волны руками влево и вправо, грудной поп, ролл плечами, приставные шаги влево и вправо, кросс-шаги влево и вправо, полные повороты влево и вправо и волна спиной.

Хотите выучить больше джаза/современной хореографии: найдите Jazz / Contemporary / Dance на [Mixamo](https://www.mixamo.com/), при скачивании выберите формат **FBX Binary** и Skin — **Without Skin**, затем импортируйте в «Танцы → Импортировать файлы моушен-капчера» (можно выбрать сразу десятки файлов; они конвертируются по одному, повреждённые файлы выводятся отдельным списком, не мешая остальным). При импорте автоматически распознаётся скелет (Mixamo, CMU, распространённые BVH, VRMA), корректируются оси и ориентация, выравниваются различия поз A/T, сглаживается дрожь захвата и обрезаются статичные фрагменты в начале и конце; сконвертированные данные сохраняются в `dances/` внутри локального каталога данных.

**Своя хореография**: в «Танцы → Мои постановки → Новая постановка» перетащите движения из библиотеки справа в последовательность (бросьте между двумя движениями, чтобы вставить туда), или кликните по движению, чтобы добавить его после выбранного; движения в последовательности можно переставлять перетаскиванием, удалять клавишей Delete или зеркально отражать лево-право одним кликом. Каждое движение занимает время по собственной длительности: обычные — 1 бит, повороты/волны — по своим счётам, а моушен-капчер (и импортированный, и встроенный современный) проигрывается целиком в оригинальной скорости, следующее движение начинается со следующего бита. Для выступления выберите песню и танцуйте от первого движения до конца последнего (музыка соответственно затухает); отработка по секциям автоматически делит последовательность на фрагменты примерно по 8 битов. Встроенные постановки можно «дублировать и править» как отправную точку. Постановки сохраняются в `data/data.json` в каталоге данных.

**Продвинутые постановки**: «Струящаяся Линия» делает акцент на линиях тела, волнах руками и изоляции груди и плеч; «Вращающаяся Сцена» — на боковые шаги, полные повороты и комбинации спиной. Многосчётные движения показываются целиком за 2 или 4 бита и никогда не переключаются посреди анимации.

## Скачивание и установка

Писать код не нужно: скачайте установщик для своей платформы на странице [Releases](https://github.com/aicccode/dance-tonight/releases/latest). Установка двойным щелчком — без регистрации и без активации в интернете.

| Платформа | Файл | Как установить |
|---|---|---|
| Windows 10 / 11 (x64) | `Dance.Tonight.Setup.*.exe` | Запустите. При первом запуске SmartScreen покажет «Неизвестный издатель» — нажмите «Подробнее → Выполнить в любом случае» |
| macOS (Apple silicon) | `Dance.Tonight-*-arm64.dmg` | Перетащите значок в «Программы»; нотаризация не пройдена, поэтому в первый раз: правый щелчок → «Открыть» |
| macOS (Intel) | `Dance.Tonight-*.dmg` | То же самое |
| Linux (x64) | `Dance.Tonight-*.AppImage` | `chmod +x` и запускайте; если не хватает FUSE, установите `libfuse2` |

Приложение не подписано сертификатом подписи кода, поэтому Windows и macOS предупредят о неизвестном разработчике. Весь исходный код лежит в этом репозитории — проверьте его или соберите сами по следующему разделу.

## Запуск из исходников (одинаково на трёх платформах)

Требуется Node.js 20 или новее.

```bash
npm install      # зависимости берутся с npmmirror (см. .npmrc); после установки MediaPipe/three.js/onnxruntime автоматически копируются в web/vendor
npm start
```

`web/vendor/` — генерируемый каталог, в репозитории его нет: после `npm install` скрипт `scripts/vendor.mjs` собирает его заново, копируя браузерные библиотеки из `node_modules`, а модель позы — из `assets/models/`. При установке ничего не скачивается.

В каталоге `assets/` лежат встроенные ресурсы, они включаются в сборку. В репозиторий входит только **минимальный проверочный набор** (крупные/личные ресурсы в репозиторий не попадают):

| Путь | Содержимое |
|---|---|
| `assets/models/beat_this_final0.int8.onnx` | Модель битов (Beat This! int8, MIT, см. NOTICE) |
| `assets/avatars/RealMaster.vrm` `SportGirl.vrm` | Встроенные аватары тренера (лицензия каждой модели — см. NOTICE) |
| `assets/dances/*.json` | 3 встроенных танца из моушен-капчера |
| `assets/tts/longhua_v3.1@zh/` `edge@<язык>/` | Офлайн-голосовые пакеты для всех 10 языков, распространяются с репозиторием; заменяются собственными записями в настройках |

**Минимальный проверочный сценарий**: `npm install && npm start` → Библиотека → Добавить файлы → выберите свой музыкальный файл → дождитесь анализа ритма → начните тренировку с главной страницы; или зайдите на страницу «Танцы» и сразу повторяйте встроенный танец из моушен-капчера.

**Дополнительные ресурсы**:
- VRM-аватары тренера: скачайте понравившегося персонажа с [VRoid Hub](https://hub.vroid.com/) (обратите внимание на лицензионные условия каждой модели), затем импортируйте в «Настройки → Аватар тренера»;
- Файлы моушен-капчера: на странице «Танцы» в приложении есть вход на [Mixamo](https://www.mixamo.com/); скачайте с **FBX Binary + Without Skin** и импортируйте пачкой;
- Песни: импортируйте свои; одинаковый контент хранится в одной копии.

## Перенос данных между устройствами

Приложение не выходит в сеть и не требует регистрации, все данные хранятся локально. Чтобы перенести данные на другое устройство, используйте «Настройки → Данные → Экспорт пакета данных» и создайте файл `.dtx`: выбор категорий (тренировки / вес и обхват талии / мои постановки / импортированный mocap / копии песен / анализ ритма / настройки), сжатие gzip, шифрование SM9 (режим SM4). Ключ выводится только из парольной фразы (не короче 8 символов); сама фраза в файл не записывается и никуда не отправляется. Импорт инкрементальный: содержимое сверяется, существующие записи сохраняются, добавляется только недостающее. Пакеты старых версий с «аккаунт + фраза» по-прежнему импортируются.

## Первое использование

1. **Библиотека → Добавить всю папку**: выберите свой музыкальный каталог, анализ ритма начнётся в фоне. Музыка копируется в каталог данных приложения (одинаковый контент хранится в одной копии), после чего исходные файлы можно удалить или переместить. Ранее импортированные песни досчитываются автоматически при запуске.
2. При переходе со старой версии: в **Настройки → Данные** есть «Импорт старых данных» (`legacy.json`: тренировки, вес, дата начала плана, без дублей) и «Импорт пакета анализа ритма» (`beat_pack.json`: сопоставление по отпечатку содержимого, такие песни не анализируются заново).
3. Хотите свой голос? В **Настройки → Голосовой тренер** загрузите записи с именами файлов по тексту реплик — они заменят голос текущего языка; встроенный пакет возвращается одним нажатием.
4. Сначала проработайте каждое упражнение в **Обучении упражнениям**, затем начните тренировку с главной страницы.

Советы по размещению: встаньте в 2,5–3 метрах от камеры так, чтобы всё тело было в кадре (включая лодыжки), свет — спереди. Перед каждой песней постойте прямо с опущенными руками около 1 секунды для калибровки.

| Клавиша | Действие |
|---|---|
| Пробел | Пропустить калибровку / пауза |
| Esc | Завершить текущую песню |

## Где хранятся данные

| Система | Расположение |
|---|---|
| Windows | `%APPDATA%\Dance Tonight\` |
| macOS | `~/Library/Application Support/Dance Tonight/` |
| Linux | `~/.config/Dance Tonight/` |

В этом каталоге `data/data.json` хранит прогресс, результаты и вес; `data/analysis/` — анализ ритма каждой песни; `music/` — копии импортированных песен; `tts/`, `avatars/` и `dances/` — созданные вами голоса, импортированные аватары и импортированные танцы из моушен-капчера. Исходные файлы после импорта можно удалить; для резервной копии или переезда на другой компьютер просто скопируйте весь каталог. При удалении песни из библиотеки удаляется и её копия в `music/` (ваши исходные файлы не затрагиваются).

## Разработка

```bash
npm test                          # юнит-тесты и покрытие
python3 scripts/gen_voices_edge.py  # опционально: пересобрать голосовые пакеты для остальных 9 языков (pip install edge-tts)
npm run test:coach                # 14 базовых танцевальных движений × 3 VRM, реальные суставы подаются в судью
npm run test:motion               # 13 продвинутых движений × 5 фаз × 3 VRM, проверка и скриншоты
npm run test:mocap                # танцы моушен-капчера × 3 VRM, проверка рендера + интерфейс/импорт обучения
npm run e2e                       # полный цикл Electron + оба регресса тренера выше
DT_E2E_EXE=dist/linux-unpacked/dance-tonight npm run e2e   # тестирование собранной программы
node e2e/pose_gallery.mjs         # сводный лист всех фитнес/танцевальных поз (средний кадр непрерывных движений)
node e2e/coach_motion.mjs /tmp/dt-motion  # контактный лист движений пяти фаз
node scripts/eval_beats.mjs <каталог-песен> <эталонный-результат.json> beatthis   # оценка точности битов
```

Структура каталогов:

| Каталог | Содержимое |
|---|---|
| `electron/` | Главный процесс: окна, протокол `app://` (междоменная изоляция, нужна для многопоточности WASM), межпроцессные вызовы, локальное JSON-хранилище, управление голосовыми пакетами, управление VRM |
| `web/js/core/` | Каталог движений, 100-дневный план, генерация карт, голосовые реплики. Общий для главного процесса и интерфейса |
| `web/js/analysis/` | Алгоритм битов на чистом JS, пре/постобработка Beat This!, аналитический Worker |
| `web/js/coach/` | 3D-тренер: three.js + three-vrm, а также позы и временные кривые |
| `web/js/voice/` | Тайминг голосовых подсказок (чистые функции) и воспроизведение через Web Audio |

## Известные ограничения

- Пороги распознавания движений проверены только на синтетических позах, **на реальных людях ещё не откалиброваны**. Если движение выполнено верно, но баллы всё время не добираются, напишите мне или поправьте `MATCHERS` в `web/js/judge.js`.
- Распознавание использует только 2D-вид спереди и плохо различает направление «вперёд-назад» и движения спиной. Поэтому **фитнес-упражнения ограничены позами, легко детектируемыми спереди; повороты, положения спиной и движения с глубиной применяются только для обучающего танцевального режима**, без оценки по совпадению суставов.
- Пороги базовых танцевальных движений откалиброваны только на синтетических позах; если при реальном танце оценки кажутся слишком мягкими или строгими, настройте `DANCE_MATCHERS` в `web/js/dance/dancemoves.js`. Продвинутые обучающие движения оцениваются по завершению повторения, а не по точности реальной танцевальной позы.
- Сборки для Windows и macOS до сих пор пакетировались только на Linux, **на реальных машинах ещё не тестировались**.
